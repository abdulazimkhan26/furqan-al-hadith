# furqan-al-hadith
Furqan al-Hadith (فرقان الحديث): a hadith reference app that presents primary-source comparisons across Sunni, Shia, and Ahmadiyya traditions, so readers can verify claims against the Quran and authentic hadith, and learn to distinguish truth (Haqq - حق) from falsehood (Batil - باطل).
\nTopics: hadith, quran, islam, ahlus-sunnah, hadith-database, json, comparative-religion, tabayyun
